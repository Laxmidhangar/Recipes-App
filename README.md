# 🍴 Recipe App

A simple full-stack Recipe App built using **React, Node.js, Express.js, and MongoDB**.

## 🚀 Features

* View recipes
* Search recipes
* Filter by category
* View recipe details
* Add new recipes
* Edit recipes
* Delete recipes

## 🛠️ Technologies Used

* React
* Node.js
* Express.js
* MongoDB
* Mongoose
* CSS

## 📁 Project Structure

```text
recipe-app
├── backend
└── frontend
```

## ▶️ Run the Project

### Backend

```bash
cd backend
npm install
npm run dev
```

Backend runs on:

```text
http://localhost:5000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

## 🔗 API Endpoints

```text
GET     /api/recipes
GET     /api/recipes/:id
POST    /api/recipes
PUT     /api/recipes/:id
DELETE  /api/recipes/:id
```

## 📌 Project

This project was created to practice **REST APIs, CRUD operations, MongoDB integration, and React API integration**.
